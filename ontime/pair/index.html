Pair a phone with OnTime

This code pairs the OnTime phone app with OnTime on your computer. When the app is on this phone, the code opens it directly.

Install the OnTime app on this phone, then point the camera at the code on your computer again. If the app is installed and this page still opened, open the app once, then try again. A code works once, for a few minutes; your computer can show a new one at any time.
